기부하기

시스템에서 기부사항을 처리중 입니다.

기부해주셔서 감사드립니다.

귀하의 기부처리가 진행중입니다. 3분~5분정도 소요될 예정입니다.

결제 완료 후 아래 확인 버튼을 클릭 하시면 마이페이지에서 귀하의 기부 처리 현황을 확인하실수 있습니다.

" 마이페이지 > 기부내역현황 "

기부내역현황 목록에서 귀하가 기부하신 항목이 “미확인”으로 처리 되어 있으신 경우 5분후에 다시 “미확인＂을 클릭 하시면 정상적으로 납부일자가 표시됩니다.

계속 처리가 안되실 경우 관리자 ( 홍길동 / 031-0000-0000 ) 에게 연락을 주시면 확인이 가능합니다.
